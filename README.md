При компиляции и запуске данного кода в строгом порядке принимаются агрументы:
Размерность пространства;
Метод (Мюллер - 0, Хармон-Майор - 1, Полярныф - 2, Сферичесийя - 3, Кватернионный - 4, Отбраковки - 5);
Количество создаваемых точек;
Целое число (если нулевое, то направдением выхода выбирается сонаправленное с осью Ox1, если ненулевое, то выбирается случайное направление);
