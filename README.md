<p>При компиляции и запуске данного кода в строгом порядке принимаются агрументы:
<br>Размерность пространства
<br>Метод (Мюллер - 0, Хармон-Майор - 1, Полярный - 2, Сферичесий - 3, Кватернионный - 4, Отбраковки - 5)
<br>Количество создаваемых точек
<br>Целое число (если нулевое, то направдением выхода выбирается сонаправленное с осью Ox1, если ненулевое, то выбирается случайное направление)
<br>Все вводимые данный представляются в формате данныйх "int"
